# apps/api/src/modules

Uma pasta por assunto. Cada módulo terá suas rotas, suas regras e sua validação.

| Módulo | Assunto |
| --- | --- |
| `auth/` | Login dos gerentes e controle dos perfis (super admin, admin de setor, visualizador) |
| `users/` | Cadastro dos usuários do site de gestão |
| `sectors/` | Cadastro dos setores do hospital (cada um com seu link e QR Code) |
| `surveys/` | Cadastro das pesquisas e perguntas |
| `responses/` | Recebe as respostas anônimas do site da pesquisa |
| `dashboard/` | Indicadores dos dashboards e do TV Wall |
